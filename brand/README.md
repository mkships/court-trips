# Court Trips brand assets

The current approved identity is **First Light**, the court, horizon and ball/sun emblem paired with the established Court Trips wordmark.

- [Complete asset kit](first-light/README.md)
- [Asset overview](first-light/previews/asset-overview.png)
- [Illustration usage examples](first-light/previews/illustration-uses.png)
- [Downloadable kit](first-light.zip)

`first-light/` contains the current logo variants, favicons, app icons, illustration exports, social covers and usage guide. Earlier root-level icon files and `explorations/` are retained as design history; use the files in `first-light/` for new work.
